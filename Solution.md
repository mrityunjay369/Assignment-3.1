# Assignment 3.1 — Solution

## Project Summary
Built a simple two-page website with working navigation links using only HTML.

## Steps Completed
1. Created `index.html` (Home) and `about.html` (About) files.
2. Added the website name, an introduction, and a navigation bar on the home page.
3. Added Home and About links in the navigation bar.
4. Connected both pages using `<a href="">` (`index.html` and `about.html` link to each other).
5. Added a link to an external website (GitHub).
6. Used `target="_blank"` to open the external link in a new tab and `rel="noopener noreferrer"` for security.

## Link Code Used
- Internal links: `<a href="index.html">Home</a>` and `<a href="about.html">About</a>`
- External link: `<a href="https://github.com/mrityunjay369" target="_blank" rel="noopener noreferrer">GitHub</a>`
